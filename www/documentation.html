Room Control Webhook

Control4 driver — local HTTP service for third-party remote control

Properties

PropertyDefaultDescription
EnabledOnStart or stop the HTTP listener.
HTTP Port5080TCP port the server listens on.
Bind Address!allInterface to bind. !all listens on all interfaces.
PasswordemptyShared secret for authentication. Leave empty to disable auth.
Control RoomsnoneRooms allowed to receive commands.

Authentication

If Password is set, include it with every request (except /health) using any of these methods:

  • Authorization: Bearer <password>
  • HTTP Basic auth — password field must match (username is ignored)
  • X-Control4-Password: <password> header
  • X-API-Key: <password> header
  • password=<password> query string or form/JSON body field

Room Targeting

The room parameter accepts:

  • A numeric room ID: room=12
  • A room name (case-insensitive): room=Living+Room
  • A comma-separated list: room=12,34 or room=Living+Room,Bedroom
  • The literal string all to target all selected rooms simultaneously

Endpoints

All endpoints return JSON. All endpoints except /health require authentication when a Password is set.

GET /health

Unauthenticated health check.

{
  "ok": true,
  "status": "enabled",
  "version": "1.0.0",
  "port": 5080
}
GET /rooms

List all rooms in the project and which are selected for control.

{
  "ok": true,
  "rooms": [
    { "id": 12, "name": "Living Room", "allowed": true },
    { "id": 34, "name": "Bedroom",     "allowed": false }
  ],
  "selected": [12],
  "allow_unselected_rooms": false
}
GET /commands

List all available commands. direct commands are sent straight to the room. action commands support tap, press, release, and/or click.

{
  "ok": true,
  "commands": [
    { "name": "PLAYPAUSE", "kind": "direct", "sequence": ["PLAYPAUSE"] },
    { "name": "VOLUME_UP", "kind": "action", "button": 359, "actions": ["tap","press","release","click"] }
  ],
  "raw_enabled": false
}
GET / POST /command

Send a room command. Parameters may be supplied as query string, form body, or JSON body.

ParameterRequiredDescription
roomYesRoom ID, name, comma list, or all
commandYesCommand name, e.g. PLAYPAUSE, ROOM_OFF
actionNotap (default), press, release, or click
paramsNoJSON object passed to C4:SendToDevice

GET example

GET /command?room=12&command=PLAYPAUSE
Authorization: Bearer mypassword

POST example

POST /command
{ "room": "Living Room", "command": "VOLUME_UP", "action": "tap" }

Response

{ "ok": true, "sequence": ["PLAYPAUSE"], "sent": [{ "room": 12, "ok": true }] }
GET /presets

Return per-room source preset configuration and available Watch/Listen sources for each selected room.

{
  "ok": true,
  "sources": {
    "12": [
      { "id": 456, "name": "Apple TV", "type": "watch", "hidden": false },
      { "id": 789, "name": "Spotify",  "type": "listen","hidden": false }
    ]
  },
  "presets": {
    "12": [
      { "index": 1, "name": "Movie", "source": 456, "source_type": "watch", "source_name": "Apple TV" }
    ]
  },
  "max_presets_per_room": 5
}
POST /presets

Save source presets for one room. Optionally include media for broadcast audio media selection.

POST /presets
{
  "room": 12,
  "presets": [
    { "name": "Movie", "source": 456, "source_type": "watch" },
    { "name": "Music", "source": 789, "source_type": "listen" }
  ]
}
GET / POST /preset

Run a saved source preset by index or name. The driver selects the source using SELECT_VIDEO_DEVICE, SELECT_AUDIO_DEVICE, or SELECT_AUDIO_MEDIA as appropriate.

ParameterRequiredDescription
roomYesRoom ID, name, list, or all
presetYesPreset index (1, 2, …) or preset name

GET example

GET /preset?room=12&preset=Movie
Authorization: Bearer mypassword

POST example

POST /preset
{ "room": "Living Room", "preset": "Movie" }
